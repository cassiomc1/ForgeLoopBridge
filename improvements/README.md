# Self-Improvement Records

This directory contains standardized execution post-mortem logs generated automatically by the Master-Agent Bridge.

Every execution creates a timestamped markdown file following the pattern:
```
<task_name>-<YYYY-MM-DD>-<HH-MM-SS>.md
```

## Structure of an Improvement Record
Each file captures:
1. **Executive Summary**: Overview of the execution.
2. **Friction Points & Identified Issues**: Blockers, ambiguities, or unexpected failures.
3. **Recommended System Improvements**: Concrete architecture, documentation, test, or tooling enhancements.
4. **Concrete Action Items & Next Steps**: Actionable tasks to evolve the system.

All files are created in English and are meant to continuously guide future development cycles.
