## Observer, Worker, and outbox

- Live Execution Observer tests pass. It remains disabled by default, read-only,
  E2EE-required, allow-listed, bounded, shell-free, credential-safe, and without
  lifecycle/evidence authority or accidental task execution.
- Worker tests cover `once`, bounded idle-poll, daemon, `--max-idle-polls`,
  `WAITING_FOR_ENGINEER`, exit/error markers, cursor progression, safe handoff,
  and no unsafe conversion of bounded mode into an infinite daemon.
- Outbox/retry tests cover at-least-once delivery, HTTP 408/425/429/5xx,
  bounded backoff and Retry-After, persistent retry state, permanent failure
  quarantine, credential exclusion, and atomic restricted persistence.
